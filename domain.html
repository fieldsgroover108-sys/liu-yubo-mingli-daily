把生活拆开，
才知道怎么动。

这里不重复一级列表，而是把每个领域变成一段可执行的判断：先说你今天该怎么做，再说明为什么，最后把每句话接到三级台账。

身体健康与状态

照顾基础状态，不做医学诊断
Energy / 能量

别把疲惫误判成能力下降

先保证吃饭、喝水和短时走动。身体状态稳住后，再判断工作是不是真的难。 (八字·身弱倾向)

Sleep / 睡眠

给大脑一个明确的收工动作

睡前写下明天第一步，让未完成事项有位置，不必在床上继续排演。 (综合推导·执行建议)

Rhythm / 节奏

上午判断，下午跟进，晚上整理

把高消耗的决定放在前面，把沟通和收束放到后面。 (八字·日度输入)

情绪与内在秩序

先命名，再行动
Name / 命名

先说清楚你在担心什么

把“有点烦”改成一个具体问题：是等待、失控、还是不知道下一步。情绪被命名后，才有机会被处理。 (综合推导·情绪整理)

Close / 收束

不要用反复想象替代一次小行动

今天只做一个能减少不确定性的动作，然后把剩余问题留到明天。 (综合推导·行动建议)

事业与工作

让推进变得可验证
Focus / 主目标

只设一个主目标，其他事项排队

今天最有价值的不是做得最多，而是让一个节点从“等待判断”进入“可以继续”。 (八字·用神取金)

看证据 ↗
Meeting / 会议

会前写清我要什么、底线是什么、谁负责下一步

把沟通从表达态度，改成交换信息和确认动作。 (旺衰/调候·结构解释)

看证据 ↗
Project / 项目

把模糊项目拆成今天能验证的最小动作

先交付一个可检查的中间结果，避免用长时间准备掩盖没有推进。 (综合推导·行动建议)

感情、爱情与择偶

提高接触质量，不虚构对象
Filter / 筛选

优先观察稳定性、学习力和边界感

吸引力可以是开始，但持续的回应、清楚的表达和稳定的行动才是判断材料。 (综合推导·择偶策略)

看证据 ↗
Channel / 渠道

去长期课程、行业活动和稳定兴趣社群

让关系在重复相处里自然显形，减少随机接触带来的误判。 (西占·热带黄道)

Opening / 开场

围绕对方正在做的事提具体问题

真诚的好奇比泛泛夸赞更容易形成有内容的来回。 (综合推导·社交策略)

财务与资源

先核实，再扩张
Cash / 现金流

先看付款节点和真实回报

今天不急着用想象中的收益替代手里的现金流，先把承诺、成本和回款写清楚。 (八字·资源配置)

Pause / 延迟

非必要消费延迟 24 小时

把冲动和真正需要分开，给决定留一个可撤回的窗口。 (综合推导·风险控制)

社交、人脉与外部机会

具体连接胜过泛泛热闹
Reach / 联系

主动联系一个高质量关系节点

带着一个具体问题去联系，让对方知道你需要什么，也知道你能推进什么。 (西占·热带黄道)

Boundary / 边界

不因孤独快速承诺，也不冷处理测试别人

把关系当作持续观察，而不是一次性证明题。 (综合推导·关系边界)
